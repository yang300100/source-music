播放器引擎 — 音乐播放的完整链路

基于鸿蒙 AVPlayer，从用户点播放到声音出来的全流程

🎯 用户体验流程

用户在搜索结果里 点某首歌

→ 播放器判断：这首歌在当前音源优先级最高的那个源里

→ 调用音源的 getMusicInfo 获取真实播放 URL

→ URL 交给 AVPlayer，开始缓冲 → 出声

→ 同时获取歌词 → 显示在播放页上

→ 如果这个源的 URL 失效了 → 自动换下一个源重试

→ 听完这首 → 如果是歌单模式，自动切下一首

播放器状态机 — 这首歌在整个生命周期中的状态
⏹ 空闲 → 点播放 → 🔍 获取URL → 拿到 → ⚡ 缓冲中 → 就绪 → ▶ 播放中 → 结束/切歌 → ⏹ 空闲
⏸ 暂停 ↔ 随时切换 ▶ 播放中 | ❌ URL失效 → 自动换源 → 🔍 获取URL

⚖️ 播放能力对比

能力 AVPlayer（我们选的） AudioRenderer（没选）
网络流媒体 ✅ 传 URL 直接播 ❌ 需自己下载解码
格式支持 ✅ MP3/FLAC/AAC/OGG/WAV ⚠️ 需自己编解码
后台播放 ✅ 系统级后台 + 通知栏控制 ⚠️ 需自行管理后台任务
开发难度 ✅ 几行代码出声音 ❌ 需深入音频底层
均衡器/音效 ⚠️ 有限支持 ✅ 完全自由控制
音频可视化 ⚠️ 间接实现 ✅ 直接拿到波形数据
